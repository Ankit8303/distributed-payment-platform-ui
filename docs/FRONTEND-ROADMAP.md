# Frontend Roadmap

| Phase | Scope | Boundary |
|---|---|---|
| F0 | Architecture, methodology, tooling | No business feature |
| F1 | Authentication/session | No payment UI |
| F2 | Accounts/dashboard | No admin |
| F3 | Payments | No refunds/payouts |
| F4 | Transactions/ledger | Presentation only |
| F5 | Refunds/payouts | Controlled workflows |
| F6 | Reconciliation | Operational visibility |
| F7 | Admin operations | Backend remains authority |
| F8 | Security/UX/accessibility/performance hardening | No new business capability |
| F9 | Production integration/release | Deployment/readiness |

Each phase is frozen before the next phase begins.
